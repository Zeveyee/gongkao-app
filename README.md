# 考公备考助手

## 项目简介

一款面向考公备考的移动端 Web App，竖屏手机优先，支持打包为手机APP。

**备考周期**: 2026-08-05 ~ 2026-11-30

## 📱 手机桌面安装（最常用）

本项目已配置为 **PWA 应用**，支持直接安装到手机桌面，像原生App一样使用（独立图标、全屏、离线可用）。

### 安卓手机（Chrome / Edge / 国产浏览器）

1. **先把项目部署到能访问的网址**（见下方"部署方式"），用手机浏览器打开该网址
2. 点击浏览器菜单（右上角 ⋮ 或 三横线）
3. 选择 **"添加到主屏幕"** 或 **"安装应用"**
4. 桌面出现"考公备考"图标，点击即可全屏使用，断网也能用

> 推荐用 Chrome / Edge 浏览器，兼容性最佳。国产浏览器（QQ、UC、百度）大多也支持"添加到桌面"。

### 苹果 iPhone（Safari）

1. 用 **Safari** 打开应用网址（注意：iPhone 只能用 Safari 安装，Chrome 不行）
2. 点击底部 **分享按钮**（方框+向上箭头）
3. 选择 **"添加到主屏幕"**
4. 点击"添加"，桌面出现"考公备考"图标

> iPhone 安装后即为独立全屏App，图标长按可管理。Service Worker 离线缓存同样生效。

### 微信内打开怎么办？

微信内置浏览器不支持安装。请点击右上角 **⋯ → 在浏览器打开**，切换到 Chrome/Safari 后再按上述步骤安装。

## 运行方式

### 方式一：本地HTTP服务器（开发调试）
```bash
cd /path/to/gongkao-app
python3 -m http.server 8090
# 浏览器访问 http://localhost:8090
```

### 方式二：部署到服务器（手机访问用）
将整个 `gongkao-app` 目录上传到任何静态Web服务器即可（无需后端），手机浏览器访问对应网址即可安装到桌面。免费方案：
- **GitHub Pages**：上传到仓库，开启 Pages
- **Vercel / Netlify / Cloudflare Pages**：拖拽目录即可部署
- **内网穿透**：用 ngrok、cpolar 把本地 8090 端口暴露到公网

### 方式三：打包为原生APP（上架应用商店用）
推荐使用以下工具将本Web App打包为手机APP：
- **HBuilderX** (国内主流，国产软件原生支持)
- **Cordova** / **Capacitor** (国际通用)

操作步骤（HBuilderX 为例）：
1. 新建 Wap2App 项目，将本目录所有文件复制到项目根目录
2. 配置图标、启动图、包名等
3. 编译生成 Android/iOS 安装包

## 功能模块

| Tab | 功能 | 说明 |
|-----|------|------|
| 1 | 今日计划 | 任务扇形饼图、固定复盘任务、休息日提示、自定义任务 |
| 2 | 刷题记录 | 行测/申论双标签切换、刷题趋势曲线、历史列表 |
| 3 | 题本库 | 行测题本、申论题本、二级条目、薄弱项排行 |
| 4 | 阶段总览 | 8-11月四大阶段、学习小模块点亮、倒计时 |
| 5 | 体重记录 | 早/晚体重录入、双曲线趋势、最高/最低统计 |
| 6 | 设置 | 自动顺延开关、回收站、备份导入导出、一键清空 |

## 核心特性

- ✅ **完全离线**：所有数据保存在浏览器 localStorage，无需后端
- ✅ **软删除回收站**：所有类型数据可移入回收站，支持单条/全部复原或永久删除
- ✅ **休息日核心逻辑**：标记休息日当天不执行任务自动顺延，不计入完成/未完成天数统计
- ✅ **数据校验**：所有数字输入校验，拦截负数、非数字，除零保护
- ✅ **二次确认**：删除、永久删除、导入备份、一键清空强制二次确认
- ✅ **配色固定**：主色 #9698E7、辅助色 #EECIDD、次要 #D1D0EF、页面背景 #FCF8F8

## 休息日规则说明

1. 日历页面**长按日期**可快速切换休息日标记
2. 休息日显示浅紫色 `#D1D0EF` 色块，右上角有"休"字
3. 休息日当天任务**不会自动顺延**到次日
4. 休息日**不计入**完成天数/未完成天数统计
5. 休息日仍可手动新增/完成任务、录入刷题/体重
6. 今日计划页面如当日为休息日，顶部显示提示

## 任务顺延规则

1. 仅在**非休息日**生效
2. 同一个原始任务**不会重复复制多条**
3. 顺延任务展示"已顺延N次"标签
4. 软删除的任务**终止顺延**
5. 系统固定复盘任务**永远不顺延**
6. 设置页面可关闭自动顺延总开关

## 数据备份

设置页面提供：
- **导出备份**：下载 JSON 文件
- **导入备份**：从 JSON 文件恢复
- **一键清空**：二次确认后清空所有数据

## 技术栈

- 纯原生 HTML + CSS + JavaScript
- 无后端依赖
- 无构建步骤
- 图表采用纯 SVG 实现，无需第三方库
- 数据存储：localStorage

## 使用技巧

1. **首次使用**：建议先在"今日计划"添加几个任务，再切换到"日历"查看色块
2. **刷题录入**：先在"题本库"创建刷题本和二级条目，再到"刷题记录"录入
3. **阶段管理**：在"阶段总览"展开阶段卡片，新增学习小模块并点亮打卡
4. **数据安全**：定期使用"设置 → 导出备份"保存数据
